## 设计变量与组件

白 `#ffffff`、侧栏 `#f5f5f6`、石墨 `#202124`、辅助文字 `#686d76`、分隔 `#e3e4e7`、焦点/链接蓝 `#3568a8`。深色用中性灰。主按钮炭黑；8px间距节奏、8–12px圆角；正文15px、辅助13px、标题30px。系统中文字体 PingFang SC 与系统无衬线保持清晰；数据使用等宽数字。

共享 App/Shell、PageHeader、Tabs、Button、Field、Status、Notice、表格布局样式、Inspector、Snapshot、Metrics、Chart、AgentPanel、Dialog、RequestCard、Empty。模态以原生 dialog 管理焦点、Esc与返回焦点；表格有可访问名称、选择与排序；无位图页面和透明热点。图表、表格和指标消费同一对象。

大于1280px显示详情Agent；640–1279px侧栏收窄、Agent按需抽屉；小于640px侧栏菜单抽屉，四主区仍直接可切换，表单单列。正文不因宽度缩小。底部操作与Agent输入有独立布局空间，不能遮挡滚动内容。所有外观选项实际生效。

## 新对象与行为

Research：id、名称、目标、绑定资源、当前修订、笔记。DraftRevision：递增 revision、数据/模板、参数、成本、区间。Proposal：自身身份、基线修订及快照、建议差异、状态；保留原提案。DatasetVersion：不可变身份、行数、字段、范围、来源、结构问题。Experiment：身份、冻结输入、请求、状态、进度、报告身份。FrozenReport：独立输入、权益序列、交易；收益/回撤/费用/交易数从这些数据推导。

Batch：固定输入、选定参数组合、成员实验 ID。Holdout：来源报告、冻结参数、独立后续数据及报告。Candidate：证据 ID、人工决定与理由；不含启动授权。Simulation：候选、配置版本、资金/成本/限额、最后确认进程状态、独立观测快照、启动/停止请求。AgentTask：明确标记的演示提问/回答、对象上下文、证据引用、工具活动。Request：稳定 ID、幂等键、操作、目标、提交/查询时间、状态。

动作统一返回更新后的对象/请求或结构化错误（字段、版本冲突、读取失败、未找到、存储失败）。组件只调用新的异步 ScenarioAdapter，不依赖 URL/API 类型。

## 状态与一致性

- 基线研究r4=20/60、E-021/REP-021冻结r4；提案20→30应用生成r5，实验数不变；后续修改不能改变报告。
- 确认实验冻结数据、参数、成本、版本、区间；匹配输入优先提示可复用报告。结果未知保留请求，显式查询，绝不重发。
- 保存配置→未启动→独立确认启动→运行中。停止请求 pending/unknown 与进程状态分开，只有查询取得确认后才 stopped；观测陈旧不等于停止。
- 版本冲突保留三份值（基线、建议、当前），阻止过期应用；显式重新生成保留原案。
- 编辑错误贴近表单，保留输入。导航前继续编辑/放弃/保存并离开；保存失败不离开。编辑缓冲与正式修订分开。
- 待办计数从提案、候选、请求状态派生。延后有可恢复列表。多处同一对象指标完全一致。

## 场景、存储与复位

集中 fixtures + 纯动作/计算 + 异步适配器。版本化、隔离 localStorage 键 `quine.frontend-v3.demo.v1`，不访问正式数据目录，不接受真实密钥。草稿缓冲与保存数据分离；刷新恢复明确。存储错误可见并禁止谎报成功。

确定性基线、空工作区、读取失败、版本冲突、实验未知、陈旧观测、停止未知、模型测试失败在独立开发验收面板中选择（特殊 URL `/#/dev` 入口），普通流程无调试开关。复位只删除演示键，已打开任务失效，不触碰用户工作区。所有对话与执行均标明演示。

CSV本地解析、字段映射、日期/数字/OHLC/重复时间校验；问题行禁止发布；发布新不可变演示版本。模型测试与保存独立，无网络请求，密钥输入使用不可编辑演示占位。

## 实施与验收顺序

1. 先为冻结/提案冲突/请求去重/停止确认/CSV校验写行为测试，再实现模型、fixtures、适配器和外壳。
2. 完成新建→绑定→草稿→冻结确认→进度→报告/交易/输入；覆盖应用r5和冻结r4。
3. 批次配置/筛选/比较、留出双报告、候选理由/确认；全部从研究和记录可达。
4. 模拟保存/启动/观察/检查器/停止/查询恢复。
5. 数据导入、模板登记、模型连接、实盘预览、设置、待办、搜索与通用恢复。
6. lint、类型、关键状态测试、构建；真实 Chromium 全流程、逐页面截图、深色/窄窗、键盘/IME composition、刷新/返回、重复点击/取消/失败恢复；一轮只读主审与集中修复。

验收清单唯一入口为同目录 coverage.md：每项图号对应实现、可达路径、视觉与功能证据。重点额外探查：提交中刷新、旧版本确认、保存失败时离开、停止未知重复点击、中文组合输入Enter。
