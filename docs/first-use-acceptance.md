# QUINE 桌面首次使用验收卡

最终产品验收对象是**实际安装的 Mac 桌面候选**。当前尚未公开发布，没有公开下载地址；使用明确交付给你的候选。
浏览器只是内部测试载体，不能替代本卡的原生结果。以下每项未亲自执行前均为 **UNVERIFIED**。

## 1. 打开候选并确认工作区

正常打开交付的应用，在 v3 左上方点击**本地研究空间**核对当前位置。使用你自己的全新工作区和有权使用的 CSV。
若需切换，选择已有空目录，保存后等待当前工作结束、正常退出再打开；保存本身不移动数据。
不要同时打开另一个同工作区实例，不要为运行候选修改系统安全设置。
没有模型连接时先完成想法保存、数据检查和本地回测；不需要在终端填 key 或打开浏览器地址。

## 2. 导入并绑定自己的 CSV

**数据资源 → 导入 CSV**，选择**自定义列映射**。逐个目的字段只从自己的表头中选列，
明确时间戳格式、时区、来源、许可及可用性策略，不凭空补数据。先预览，只有整份源文件被接受才发布版本。
时间戳字段由可用性策略决定（2个或3个）；上传不等于已核验 PIT 可用性，来源和许可是你的声明。

回到目标研究，明确绑定刚发布的数据版本；上传不会自动选中。找不到或无法绑定时记录阻塞，不能用其他数据
代替并宣布通过。暂存稍后继续和丢弃导入应有区别；丢弃草稿不能删除已入库数据。

## 3. 保存草稿、确认实验、读报告

1. 新建研究并保存自己的问题。草稿保存不要求模型，不应自动运行。
2. 核对草稿版本、策略、标的、数据版本、区间、样本性质、初始资金/币种与成本假设。
3. 预览实验并单独确认开始一次真实本地回测；确认页不是通过浏览器前后退自动恢复的授权。
4. 关闭 AI 面板，报告仍能独立说明冻结来源及真实指标；缺失、过期与确实为空要区分。
5. 刷新原请求，核对同一运行与报告，没有再次派发。转到资源/设置后返回，应恢复来源对象和报告位置。

此路径不启动模拟或实盘。候选接受不等于执行授权；不要用草稿勾选替代冻结候选和独立启动确认。
结果未知时仅查询原请求，不盲目重发；取消不能回滚已开始的工作或清除其真实状态。

## 4. AI 与原生输入（仅在有合适的测试条件时）

模型唯一编辑位置为**资源 → 模型连接**。保存配置不等于认证或模型调用；是否使用付费模型由用户另行决定，
本卡不要求购买或调用。内部验收可用本地脚本模型；其通过不能写成真实提供方验证通过。

核对提案的目标草稿/版本、diff与依据；Apply只修改草稿，不执行。切换对象后，迟到回复不能污染新对象。
在原生窗口验证 `/` 实际配置及作用域、发送/停止、中文IME候选确认 Enter 不误发送、Shift+Enter换行、
显式发送仅一次。发送禁用状态不能证明完整输入法行为。不得把 key 放进消息或截图。
