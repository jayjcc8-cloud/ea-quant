# 首次使用人工验收卡（独立用户，1 页）

给你自己：在**你自己的全新工作区**上，用一份你**有权使用**的真实 CSV，由你独自走一遍，不需要写 JSON。
不涉及真实资金、Paper、交易通道、发布或任何交易动作。

命令都在**仓库根目录**执行，`--workspace` 指向**同一个全新目录**（不要指向仓库内部）。
各开关的完整说明见[本地研究启动](local-research-start.md)。

## 1. 同一个新工作区：先检查，再离线启动（不花钱、不发模型请求）

```bash
python3 scripts/start_research.py --check --offline --workspace <你的全新工作区>   # 只读：只打印将要做的事
python3 scripts/start_research.py --offline --workspace <你的全新工作区>           # 用同样参数启动
```

两次必须是**同一个新工作区**。`--check` 报告 workspace、场景根、UI 构建、端口、模型选择；与预期不符就停，
此时什么都没发生。`--offline` 不写 `model` 配置、不要 key、**不可能**发出模型请求。启动后终端打印 loopback
地址，用它打开浏览器。**离线只覆盖 CSV 导入与本地回测**：草稿与结论需要模型，必须走第 3 步。

## 2. 上传你自己的 CSV（引导映射，不写 JSON）

Research workspace → **Data, declarations and local packages → Controlled data upload**：
选 **Explicit mapping of my own file**（**不要**切到 Advanced JSON），逐个目的字段只从你这份文件
**自己的表头行**里选列（页面不读数据行、不推断值、不预填）；时间戳按本主机的封闭允许列表选确切格式，
**时区由你声明**。先**预览**并逐项核对表头、列、时区、元数据，**只有预览接受了整份源文件**才**发布**该版本。
时间戳字段数量由可用性策略决定（2 个或 3 个，**不是**固定三个）。上传**永远不会**被报告为已核验的
PIT 可用性；来源与许可字段是你的声明，不是法律核验。

## 3.（可选）你自己决定付费跑模型时才做

只有你选择付费才需要这步：**先停掉你自己的离线进程**，再用**同一个工作区、同一个端口**启动

```bash
python3 scripts/start_research.py --provider deepseek --workspace <同一个工作区>
```

安装成功后，启动器在真实终端用 `getpass` 私下索取 key；key 只作为环境变量进入这一个子进程，不进参数、
不落文件、不进日志。配了 key ≠ 已验证（设置状态仍显示 `request_validation: not_verified`）。

## 4. 研究闭环：确认用的是你自己的数据与问题

1. **Create draft 需要 provider**（第 3 步）。写你自己的问题，**复核 Capability selection**（留空＝主机默认路由），
   并确认**你发布的那份数据版本**真的被选进这份能力/草稿里 —— 上传**不会**自动选中它。找不到或选不了这份版本，
   就**记一条阻塞**（第 6 步），**不要**改用 JSON 编辑器绕过。
2. 读 **Draft specification**（标的、初始资金、参数、假设）与冻结预算/已用量，确认这就是你要问的问题。
3. 只有你亲自点 **Confirm spec and start real backtest** 才会开始一次真实本地回测；确认是**独立的一步**。
4. 结束后先看报告数字；需要结论时点 **Interpret this run**（显式，最多一次模型调用，不新起回测）。
5. 点 **Refresh**，确认重新读到的是持久化后的同一份记录。

没有真实 provider 时，第 1–5 步**不能**声称通过；`--check` 与离线启动只能覆盖第 2 步和本地回测。

## 5. 失败时怎么走

- 页面写明 *retry resumes the failed step in place* 时：点 **Retry failed step**，它接着这条记录继续，不重跑整件事。
- 任务为 **failed** 时：**Prepare a new experiment** 起初不可用（同一 idea 已被这条 failed 记录占用，主机拒绝第二条）。
  按页面提示**先点 Cancel task**（已有运行/报告保留，不回滚任何已派发的工作），返回后再准备新实验。
- **结论被拒**（interpretation error）：**没有**原地重试；可直接**另起新实验**。
- 提交结果未知（outcome unknown）：页面不自动重发、也不给重试按钮，只能另起新实验。
- 新实验只带你自己的 idea 与来源任务号，**不复制**规格、运行、报告、预算或确认；创建与确认都要你自己再点。
